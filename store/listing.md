### 说明（详细描述）

```
在 X（Twitter）的时间线、粉丝列表、关注列表里，直接在用户名旁边显示粉丝数。

X 只在个人主页和悬停卡片里显示粉丝数，刷时间线、翻粉丝列表时看不到。装上这个扩展后：
• 刷时间线时，一眼看出发言的人有多少粉丝，引用推文和推荐关注里也有
• 翻「认证关注者」「关注者」列表时，看出哪些有影响力的人关注了你
• 翻别人的「正在关注」列表找值得关注的账号时，多一个参考
• 翻自己的「正在关注」列表时，没回关你的人会标上红色「未回关」

功能
• 数字格式可选：中文「粉丝 17.4万」或英文「17.4K followers」
• 按粉丝量级着色：灰（不到 1 千）、蓝（1 千以上）、紫（1 万以上）、橙（10 万以上）
• 时间线推文和用户列表可分别开关
• 鼠标悬停查看精确粉丝数、关注数和数据更新时间
• 自动适配 X 的浅色和深色主题

原理与隐私
X 网页加载时间线、粉丝列表时，自己发出的请求里本来就带着每个用户的粉丝数。本扩展只在你的浏览器里读取这些已有的返回结果，再把数字显示到页面上：
• 不调用任何 API，不额外发请求，不需要你的登录信息
• 不上传任何数据，记录只保存在你的浏览器里，可在设置面板一键清空
• 只在 x.com 和 twitter.com 上运行

说明：本扩展是第三方工具，与 X Corp. 没有关联，也未获其认可。X 是 X Corp. 的商标。
```

## 隐私权（Privacy practices）

**单一用途说明**

```
在 x.com 和 twitter.com 页面的用户名旁显示该用户的粉丝数。粉丝数从 X 网页自身已经加载的接口返回内容中读取，不发出额外请求。
```

**storage 权限的理由**

```
保存用户的显示设置（开关、数字格式、是否按量级着色），以及在本机缓存「用户名 → 粉丝数」记录，使刷新页面后仍能立即显示。数据只保存在用户本机，不上传。
```

**主机权限的理由**（内容脚本匹配 https://x.com/* 和 https://twitter.com/*）

```
扩展的内容脚本只在 x.com 和 twitter.com 上运行：在页面内读取 X 网页自身接口返回中的公开粉丝数，并在用户名旁插入显示标签。不访问任何其他网站，不发出任何网络请求。
```

**是否使用远程代码**：否，我没有使用远程代码。

**数据使用**：勾选「网站内容」。

商店规定，即使数据只在本机处理、不上传，也要申报（User Data FAQ 第 3 条）。本扩展读取的是 X 页面返回内容里的公开用户名和粉丝数，属于网站内容。不涉及身份信息、身份验证信息、个人通讯、位置、网络记录或用户活动（不记录点击、按键，也不记录访问了哪些网址）。

三项承诺全部勾选：
- 不会出于已获批准的用例之外的目的向第三方出售或传输用户数据
- 不会出于与我的产品的单一用途无关的目的使用或转移用户数据
- 不会为了确定信用度或用于贷款而使用或转移用户数据

**隐私权政策网址**：https://docs.google.com/document/d/e/2PACX-1vQGOxwAnILwzqNBDOC1SfFkc3TMrLHJ_0o0RtVi4lvPeIduAVL98tS3a9F8Oz8OuASokPgDaOvTrcWD/pub （Google 文档「X 粉丝数显示 隐私政策 / Privacy Policy」发布到网络，内容同 `store/privacy-policy.md`；改文档后发布内容会自动更新）
