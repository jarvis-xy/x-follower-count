# 发布

仓库：<https://github.com/jarvis-xy/x-follower-count>（公开，MIT）

## 发新版本

1. 改 `extension/manifest.json` 的 `version`（`package.json` 的版本跟着改）
2. `npm test` 和 `npm run test:e2e` 全部通过
3. `npm run pack` 生成 `dist/x-follower-count-v<版本>.zip`（`dist/` 不进仓库）
4. 提交、推送，然后发 Release，附上 zip：

   ```bash
   gh release create v<版本> dist/x-follower-count-v<版本>.zip --title "v<版本>" --notes "..."
   ```

5. 商店版本用同一个 zip 在开发者信息中心上传，各字段填法见 [store/listing.md](../store/listing.md)

README 的安装步骤指向 `releases/latest`，发完 Release 不用改 README。

## 公开前检查

仓库是公开的，每次推送前确认：

- 没有密钥、本机路径、邮箱：`git grep -nIE "/Users/|@[a-z0-9.-]+\.(com|cn)|token|secret"`
- 截图和模拟数据里的账号都是虚构的。`docs/images/` 的图是从 `test/e2e/out/` 复制来的，改了弹窗或模拟页面后要重新复制，否则 README 里会留着旧图
